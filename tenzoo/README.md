# tenzoo（仮称）— ブラウザで動く点図エディタ

日本語 | [English](README.en.md)

点図作成ソフト「エーデル」と同等の機能＋αを、**インストール不要のウェブアプリ**として実装したものです。
JavaScript（ES Modules）だけで書かれており、ビルドも不要です。GitHub Pages などに置けば、
パソコン・タブレット・スマートフォンのブラウザでそのまま動きます。データはすべて端末の中で処理され、サーバーには送られません。

- 公開版：https://minatani.github.io/tenzoo/ （GitHub Pages を有効にした後）
- 起動：`index.html` を HTTP で配信して開く（ローカル確認は `python3 -m http.server 8080` → http://localhost:8080/ ）
- デモ図：`index.html?sample=demo`
- テスト：`node --test`（Node.js 20 以上）。edlprt の実物ファイルでも確かめるときは `EDLPRT_EXAMPLES=<edlprt>/examples node --test`

## 主な機能

### 描く
| 道具 | キー | 内容 |
|---|---|---|
| 選択 | V | 選択・移動・拡大縮小（四隅・辺）・回転（上の丸）、範囲選択、Shift で追加選択 |
| 点 | P | クリック／ドラッグで点を打つ。**矢印キー＋スペース／Enter でカーソル描画**（Backspace で消す） |
| 直線 | L | Shift で 15° 刻み |
| 折れ線 | Y | クリックで頂点、ダブルクリック／Enter で終了、始点クリックで閉じる |
| 曲線 | C | 通過点を置く滑らかな曲線（Catmull-Rom） |
| 円弧 | A | 始点・終点・ふくらみの3点（エーデルの円弧と同じ定義） |
| 手描き | F | フリーハンド（自動で間引き、始点近くで離すと閉じる） |
| 四角・円 | R / E | Shift で正方形・正円 |
| 点字 | B | かな・英数字 → 日本語点字（数符・外字符・つなぎ符・拗音・特殊音）。**6点入力（F D S J K L）**、タッチ用の6点ボタン。マス目（1マス=15・1行=33目盛り）に合わせて置ける |
| 記号 | K | 星・十字・四角・ひし形・丸・三角・1点（navimap-assistant・edlprt の地図記号と同じ形）。周りの点を自動で消す余白付き |
| 消しゴム | X | なぞって消す／四角の範囲を消す（図形は点に変換してから消す） |

線のスタイル：点の大きさ（大・中・小）、点の間隔、実線／破線／点線／二重線、矢印（始点・終点・両端）。
点字・記号には「周りの点を消す余白」を付けられ、線が点字や記号にかかって読みにくくなるのを防ぎます。

### 確かめる
- **点図の検査（I）**：別の図形の点どうしが近すぎる所、点が密集している所、ESA721 で打てない所の点、点字にかかる線、近すぎる記号を一覧にします（目安は navimap-assistant と同じ）
- 点字のマス目と行・マスの番号の表示（エーデルの定規と同じ 32マス×22行）、点字の読み（墨字）の重ね表示
**角には必ず点を置き**、辺を均等に割るので、触って角がわかります。

### 範囲を面で塗る（＋α）
- 塗り方：**四角／楕円／投げ縄／多角形**で範囲を指定、または**線で囲まれた所をクリックして塗りつぶし**
- 面の表現（17種）：格子点・千鳥・ベタ・横線・縦線・斜線（／＼）・格子線・斜め格子・波線・ジグザグ・破線・レンガ・市松・同心円・放射線・ランダム（砂目）
- 調整：線・点の間隔、線の中の点の間隔、角度、点の大きさ、**輪郭からの余白**（輪郭線と面の点がくっつかない）
- オプションで輪郭線も描く。描いたあとでも、選択してパターンや間隔をいつでも変えられる

### レイヤ（＋α）
- 追加・複製・削除・並べ替え・名前・表示色・表示／非表示・ロック
- **チェックしたレイヤをまとめる**：「図形のまま」または「点にして」マージ
- 選択した図形を別のレイヤへ移動、レイヤごとに別ファイルで書き出し

### 原図（下絵）と取り込み（＋α）
- PNG / JPEG / GIF / BMP / WebP / SVG を下絵として敷き、濃さ・大きさ・位置を調整してなぞれる
- **自動点図化**：下絵の暗い部分を「塗り」「輪郭」「濃淡（大中小の点）」で点にする（新しいレイヤに）
- **SVG をベクトル図形として取り込み**（line / polyline / polygon / rect / circle / ellipse / path［曲線・円弧含む］、transform 対応）

### ファイル
| 形式 | 読む | 書く | 備考 |
|---|---|---|---|
| tenzoo（.tenzoo, JSON） | ○ | ○ | 図形（ベクトル）・レイヤ・下絵・設定をすべて保持する本来の保存形式。仕様は [docs/tenzoo-format.md](docs/tenzoo-format.md)（[English](docs/tenzoo-format.en.md)、[JSON Schema](docs/tenzoo.schema.json)） |
| エーデル（.edl） | ○ | ○ | B5・A4。複数ページ・両面の拡張にも対応。実物ファイルでバイト単位の往復一致を確認 |
| エーデル（.ezi） | ○ | ○（試験的） | 線分・円弧を編集できる図形として読み込む。.edl と同時に選ぶと1つの図にまとめる |
| エーデル（.sebk） | ○ | ○（試験的） | .edl＋.ezi をまとめたもの。読み→書きでバイト単位の一致を確認（合成データ） |
| SVG | ○（図形・下絵） | ○ | 実寸（mm） |
| PDF | － | ○ | 実寸のベクトル。立体コピー原稿に |
| PNG | ○（下絵） | ○ | 150/300/600 dpi、印刷時に実寸になる解像度情報付き |
| ESA721 送信用データ（.esa） | － | ○ | edlprt・EBP と同じバイト列（点種別印刷、縦横比の補正）。tenzoo からは送らず、ファイルとして保存 |
| 印刷 | － | ○ | ブラウザの印刷で実寸 |

ブラウザ内に**自動保存**し、次に開いたときに復元します。PWA としてホーム画面に追加でき、一度開けば**オフラインでも起動**します。

### 出力先（プリンタ）プロファイル
図はベクトルで持ち、**出力するときに出力先の格子・点の種類に合わせます**。

- ESA721（エーデル互換）：ESA721 のプロッタの1ステップ（横 0.3454mm × 縦 0.3175mm、1マス=15・1行=33）、小・中・大の3種の点。用紙は点字用紙 B5（8×10インチ、図は 684 行まで。設定で 725 行まで）・A4（10×11インチ、790 行まで）
- 汎用点字プリンタ（2.5mm 格子・1種類の点）
- 20dpi 格子のプリンタ
- 立体コピー（カプセルペーパー）：格子なし、黒い点・面として PDF/PNG/SVG に
- 格子なし（ベクトルそのまま）

近すぎる点は「点どうしの最小距離」より近ければ大きい方を残してまとめます（用紙が破れるのを防止）。
プロファイルは `js/profiles.js` の一覧に足すだけで増やせます。

### 画面
- モダンな UI。パソコンでは左に道具・右にパネル、**スマートフォンでは下に道具・下から出るパネル**
- 2本指のピンチで拡大縮小・移動、ホイール／トラックパッド対応、ダークモード
- 表示：点 / 点＋図形の線 / 図形の線だけ / 触る面のイメージ

## エーデルの機能との対応

エーデルの解説サイト（ntut-braille-net.org）は開発環境のネットワーク設定で閲覧できなかったため、下表は BESE の資料（EdelPaper・EdelBook の使い方）、
edlprt・navimap-assistant の解析と、一般に知られているエーデルの機能に基づく整理です。抜けや誤りがあればご指摘ください。

| エーデルの機能 | tenzoo |
|---|---|
| 点（大・中・小）を打つ、キーボードのカーソルで描く | ○（点だけでなく、直線・折れ線・円弧・四角・円・塗り・点字も矢印キー＋Enter で） |
| 直線・連続線・円弧・曲線・円・楕円・四角 | ○（すべてベクトルで後から編集可） |
| フリーハンド | ○ |
| 塗り（面のパターン） | ○ 17種＋角度・間隔・余白・輪郭の有無 |
| 消去 | ○（消しゴム、選択して削除） |
| 範囲選択して移動・複写・削除・反転・回転 | ○（加えて拡大縮小・重なり順） |
| 点字の入力（かな変換・6点入力） | ○（漢字かな交じり文の自動点訳は未対応。読みをかなで入力） |
| 下絵（BMP）を読み込んでなぞる | ○（BMP 以外の画像・SVG も） |
| 画像からの自動点図化（Tenka 相当） | ○（簡易：塗り・輪郭・濃淡） |
| 元に戻す | ○（やり直しも、200 段） |
| 拡大表示・方眼 | ○（方眼への吸着も） |
| 点字のマス目・行番号（32マス×22行の定規） | ○（表示、マス目への吸着） |
| 点種別の印刷（小・中・大を分けて打つ）、EBP の縦横比の補正 | ○（ESA721 送信用データの書き出しで） |

| — | ＋ レイヤとマージ、ベクトル保存、他プリンタ・立体コピー用の出力、SVG/PDF/PNG、タッチ操作、オフライン動作 |

## エーデル形式について

公開仕様がないため、利用者による実物ファイル・ESA721 説明書の解析結果（[docs/format.md](docs/format.md) にまとめた）と、
[tenji-editor](https://github.com/setsukashiraishi-hub/tenji-editor)（MIT License）の解析に基づいて実装しています。

- **.edl**：点の大きさは 1=小・2=中（点字の点）・3=大。1目盛りは ESA721 の1ステップ。用紙の外の点は書き出しません。
  実物3ファイルで「読む → mm 座標に変換 → 書き戻す」がバイト単位で一致することを確認
- **.ezi**：線分（101）と円弧（102）を、エーデルと同じ「長さ÷間隔を四捨五入して等分」の方法で点にします。
  読み込んだ線は tenzoo でも同じ方法で点を置くので、そのまま書き出すと .edl と同じ点になります
  （.5 の丸め方など未解明の点があり、実物との差は1目盛り＝約0.3mm 以内）
- **.sebk**：.edl と .ezi の入れ物。`fumi.data`（点字の文書領域らしい）は構造未解明のため、読み込みでは無視し、書き出しでは空のものを付けます
- .ezi・.sebk の書き出しは、エーデル本体で開けるか未確認のため「試験的」としています。確認していただけると助かります

## スクリーンリーダでの操作

画面の部品にはすべて名前（ラベル）が付いており、操作の結果は読み上げられます（axe-core での自動検査で違反なし）。
フリーハンドや投げ縄はマウス・タッチ専用ですが、それ以外の主な作業はキーボードとスクリーンリーダだけでできます。

- **用紙でのキーボード描画**：用紙（描画領域）にフォーカスを移し（ページ先頭の「用紙へ移動」リンクでも可）、矢印キーでカーソルを動かします
  （1mm、Shift で 5mm、Ctrl で 10mm。座標とその位置にある図形を読み上げます）。Enter かスペースで、選んでいる道具をカーソルの位置で使います：
  点を打つ／直線・四角・円の始点と終点／折れ線・曲線・多角形の頂点（Shift+Enter で終了、Ctrl+Enter で閉じて終了）／円弧の3点／囲まれた所を塗る／点字を置く／図形を選ぶ／消す。
  Backspace で1つ取り消し、Escape で中止
- **W** で現在の状態（道具・作業中のレイヤ・カーソル位置とそこにある図形・選択中の図形）、**Q** で図の概要を読み上げ、**M** でカーソルを座標で移動
- **N**（またはメニュー）で「数値を指定して図形を追加」：直線・折れ線・多角形・正多角形・四角・円・円弧・点・点字を座標で作れます
- 設定パネルの **「一覧」** タブで、すべての図形をことばで確認・選択できます（例：「正方形、左上 x 143 y 128、幅 30 高さ 30、中点、間隔 2mm」）。
  **「図形」** タブで、位置・大きさ・頂点の座標・点の大きさと間隔・面の表現を数値で変更できます
- 道具バーとタブは矢印キーで移動、メニューは矢印キーと Escape で操作できます。パネルを変更してもフォーカスは同じ部品に戻ります
- レイヤはラジオボタンで作業中のレイヤを選び、表示・ロックは押しボタンの状態として読み上げられます

## 公開（GitHub Pages）

`.github/workflows/pages.yml` が、テストを実行してからサイトを GitHub Pages に公開します。

1. リポジトリの **Settings → Pages → Build and deployment → Source** を「**GitHub Actions**」にする
2. `main` に push する（または Actions 画面で「Pages」を手動実行）
3. https://minatani.github.io/tenzoo/ で開ける

既定ブランチ以外から公開する場合は、Settings → Environments → github-pages の「Deployment branches」にそのブランチを加えてください。
