# tenzoo（仮称）— ブラウザで動く点図エディタ

点図作成ソフト「エーデル」と同等の機能＋αを、**インストール不要のウェブアプリ**として実装したものです。
JavaScript（ES Modules）だけで書かれており、ビルドも不要です。GitHub Pages などに置けば、
パソコン・タブレット・スマートフォンのブラウザでそのまま動きます。データはすべて端末の中で処理され、サーバーには送られません。

- 起動：`tenzoo/index.html` を HTTP で配信して開く（ローカル確認は `cd tenzoo && python3 -m http.server 8080` → http://localhost:8080/ ）
- デモ図：`index.html?sample=demo`
- テスト：`cd tenzoo && node --test`（Node.js 20 以上）

## 主な機能

### 描く
| 道具 | キー | 内容 |
|---|---|---|
| 選択 | V | 選択・移動・拡大縮小（四隅・辺）・回転（上の丸）、範囲選択、Shift で追加選択 |
| 点 | P | クリック／ドラッグで点を打つ。**矢印キー＋スペース／Enter でカーソル描画**（Backspace で消す） |
| 直線 | L | Shift で 15° 刻み |
| 折れ線 | Y | クリックで頂点、ダブルクリック／Enter で終了、始点クリックで閉じる |
| 曲線 | C | 通過点を置く滑らかな曲線（Catmull-Rom） |
| 手描き | F | フリーハンド（自動で間引き、始点近くで離すと閉じる） |
| 四角・円 | R / E | Shift で正方形・正円 |
| 点字 | B | かな・英数字 → 日本語点字（数符・外字符・つなぎ符・拗音・特殊音）。**6点入力（F D S J K L）**、タッチ用の6点ボタン |
| 消しゴム | X | 点を消す（図形は点に変換してから消す） |

線のスタイル：点の大きさ（大・中・小）、点の間隔、実線／破線／点線、矢印（始点・終点・両端）。
**角には必ず点を置き**、辺を均等に割るので、触って角がわかります。

### 範囲を面で塗る（＋α）
- 塗り方：**四角／楕円／投げ縄／多角形**で範囲を指定、または**線で囲まれた所をクリックして塗りつぶし**
- 面の表現（16種）：格子点・千鳥・ベタ・横線・縦線・斜線（／＼）・格子線・斜め格子・波線・ジグザグ・破線・レンガ・市松・同心円・放射線・ランダム（砂目）
- 調整：線・点の間隔、線の中の点の間隔、角度、点の大きさ、**輪郭からの余白**（輪郭線と面の点がくっつかない）
- オプションで輪郭線も描く。描いたあとでも、選択してパターンや間隔をいつでも変えられる

### レイヤ（＋α）
- 追加・複製・削除・並べ替え・名前・表示色・表示／非表示・ロック
- **チェックしたレイヤをまとめる**：「図形のまま」または「点にして」マージ
- 選択した図形を別のレイヤへ移動、レイヤごとに別ファイルで書き出し

### 原図（下絵）と取り込み（＋α）
- PNG / JPEG / GIF / BMP / WebP / SVG を下絵として敷き、濃さ・大きさ・位置を調整してなぞれる
- **自動点図化**：下絵の暗い部分を「塗り」「輪郭」「濃淡（大中小の点）」で点にする（新しいレイヤに）
- **SVG をベクトル図形として取り込み**（line / polyline / polygon / rect / circle / ellipse / path［曲線・円弧含む］、transform 対応）

### ファイル
| 形式 | 読む | 書く | 備考 |
|---|---|---|---|
| tenzoo（.tenzoo, JSON） | ○ | ○ | 図形（ベクトル）・レイヤ・下絵・設定をすべて保持する本来の保存形式 |
| エーデル（.edl） | ○ | ○ | 新しい図として、または今の図にレイヤとして読み込み。実物ファイルでバイト単位の往復一致を確認 |
| エーデル（.ezi） | × | × | 仕様非公開のため未対応（理由は下記） |
| SVG | ○（図形・下絵） | ○ | 実寸（mm） |
| PDF | － | ○ | 実寸のベクトル。立体コピー原稿に |
| PNG | ○（下絵） | ○ | 150/300/600 dpi、印刷時に実寸になる解像度情報付き |
| 印刷 | － | ○ | ブラウザの印刷で実寸 |

ブラウザ内に**自動保存**し、次に開いたときに復元します。PWA としてホーム画面に追加でき、一度開けば**オフラインでも起動**します。

### 出力先（プリンタ）プロファイル
図はベクトルで持ち、**出力するときに出力先の格子・点の種類に合わせます**。

- ESA721（エーデル互換）：エーデル座標の格子（x 0.4mm × y 約0.343mm）、大・中・小の3種の点
- 汎用点字プリンタ（2.5mm 格子・1種類の点）
- 20dpi 格子のプリンタ
- 立体コピー（カプセルペーパー）：格子なし、黒い点・面として PDF/PNG/SVG に
- 格子なし（ベクトルそのまま）

近すぎる点は「点どうしの最小距離」より近ければ大きい方を残してまとめます（用紙が破れるのを防止）。
プロファイルは `js/profiles.js` の一覧に足すだけで増やせます。

### 画面
- モダンな UI。パソコンでは左に道具・右にパネル、**スマートフォンでは下に道具・下から出るパネル**
- 2本指のピンチで拡大縮小・移動、ホイール／トラックパッド対応、ダークモード
- 表示：点 / 点＋図形の線 / 図形の線だけ / 触る面のイメージ

## エーデルの機能との対応

エーデルの解説サイト（ntut-braille-net.org など）は開発環境から閲覧できなかったため、下表は一般に知られているエーデルの機能に基づく整理です。抜けや誤りがあればご指摘ください。

| エーデルの機能 | tenzoo |
|---|---|
| 点（大・中・小）を打つ、キーボードのカーソルで描く | ○（点の道具、矢印キー＋スペース） |
| 直線・連続線・曲線・円・楕円・四角 | ○（すべてベクトルで後から編集可） |
| フリーハンド | ○ |
| 塗り（面のパターン） | ○ 16種＋角度・間隔・余白・輪郭の有無 |
| 消去 | ○（消しゴム、選択して削除） |
| 範囲選択して移動・複写・削除・反転・回転 | ○（加えて拡大縮小・重なり順） |
| 点字の入力（かな変換・6点入力） | ○（漢字かな交じり文の自動点訳は未対応。読みをかなで入力） |
| 下絵（BMP）を読み込んでなぞる | ○（BMP 以外の画像・SVG も） |
| 画像からの自動点図化（Tenka 相当） | ○（簡易：塗り・輪郭・濃淡） |
| 元に戻す | ○（やり直しも、200 段） |
| 拡大表示・方眼 | ○（方眼への吸着も） |
| .edl の読み書き | ○ |
| ESA721 への RS-232C 直接印刷 | × 今回は対象外（.edl を書き出して既存の手段で印刷） |
| EdelBook（.ebk）、BES との連携 | × 未対応（今後の課題） |
| — | ＋ レイヤとマージ、ベクトル保存、他プリンタ・立体コピー用の出力、SVG/PDF/PNG、タッチ操作、オフライン動作 |

## エーデル形式について

**.edl** は公開仕様がないため、実物ファイルの解析結果に基づいて実装しています（[tenji-editor](https://github.com/setsukashiraishi-hub/tenji-editor)［MIT License］の解析を参考にし、実物3ファイルで「読む → mm 座標に変換 → 書き戻す」がバイト単位で一致することを確認）。詳細は [docs/format.md](docs/format.md)。

- 用紙名はヘッダの `EDELB5` の部分。B5 以外の書き方は未確認のため、書き出しは常に `B5`
- 1目盛りの実寸（x 0.4mm、y ≒ 0.343mm）は点字の点間隔から推定した値

**.ezi**（エーデル 6.06 以降で .edl に付随する図形データ）は、仕様が公開されておらず手元に実物もないため未対応です。
点の情報はすべて .edl に入っているので、.edl を開けば図は再現できます。**.edl と .ezi の組の見本をいただければ解析して対応できます。**

## 構成

```
tenzoo/
  index.html            画面
  css/app.css           スタイル（レスポンシブ・ダークモード）
  js/app.js             パネル・ダイアログ・ファイル操作・キー操作
  js/store.js           状態、元に戻す、図形・レイヤの操作
  js/view.js            キャンバス描画、座標変換
  js/tools.js           各道具（ポインタ・タッチ・ピンチ）
  js/model.js           データモデル（図形の輪郭・変換・当たり判定・マスク）
  js/raster.js          ベクトル → 点への変換（線・面・点字・矢印）
  js/patterns.js        面の表現
  js/profiles.js        出力先プロファイル・用紙
  js/geometry.js        幾何計算
  js/braille.js         日本語点字の変換
  js/io/edl.js          エーデル形式
  js/io/export.js       tenzoo / SVG / PNG / PDF
  js/io/import.js       画像・SVG の取り込み、自動点図化
  sw.js, manifest.webmanifest  オフライン（PWA）
  test/                 ユニットテスト（node --test）
  docs/format.md        データ形式の仕様
```

## 公開（GitHub Pages）

`.github/workflows/tenzoo-pages.yml` が、テストを実行してから `tenzoo/` を GitHub Pages に公開します。

1. リポジトリの **Settings → Pages → Build and deployment → Source** を「**GitHub Actions**」にする
2. `tenzoo/` を変更して push する（または Actions 画面で「tenzoo - GitHub Pages」を手動実行）
3. `https://<ユーザー名>.github.io/<リポジトリ名>/` で開ける

既定ブランチ以外から公開する場合は、Settings → Environments → github-pages の「Deployment branches」にそのブランチを加えてください。
