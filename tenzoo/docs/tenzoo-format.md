# tenzoo 形式（.tenzoo）仕様　第1版

日本語 | [English](tenzoo-format.en.md)

tenzoo が図を保存するときの形式です。ほかのソフトからも読み書きできるよう、ここにすべての項目を定めます。
機械で検査できる [JSON Schema](tenzoo.schema.json) もあります。

## 1. 設計の考え方

1. **ベクトルで持つ**：線・図形・面は「形」と「点の打ち方（スタイル）」で保存し、点そのものは保存しない
   （点の集まりとして作った図形だけは点を保存する）。拡大縮小、点の間隔や面の表現の変更、出力先の変更をしても
   情報が欠けない。
2. **出力先に依存しない**：座標はすべて mm。プリンタの格子や点の種類への変換は、出力のときにプロファイルで行う。
   同じファイルから ESA721（エーデル形式）、ほかの点字プリンタ、立体コピー（PDF・PNG・SVG）に出せる。
3. **点の大きさは論理名**：`S`（小）・`M`（中）・`L`（大）。実際の直径や高さは出力先が決める。
   エーデル（ESA721）では `S`=1、`M`=2（点字の点）、`L`=3。
4. **拡張できる**：JSON なので項目を足せる。読む側は知らない項目を無視し、できれば保存し直すときに残す。

## 2. ファイル

| 項目 | 内容 |
|---|---|
| 文字コード | UTF-8（BOM なし） |
| 拡張子 | `.tenzoo` |
| MIME タイプ | `application/json`（専用の型を使う場合は `application/vnd.tenzoo+json` を推奨） |
| 中身 | JSON のオブジェクト1つ |

### 座標系

- 原点は用紙の左上。x は右へ、y は下へ増える。単位は mm（小数可）。
- 角度はラジアン。正の向きは画面上で時計回り（y が下向きのため）。
- 点の位置は点の中心。

## 3. 全体の構造

```jsonc
{
  "format": "tenzoo",        // 必須。固定の文字列
  "version": 1,              // 必須。この仕様の版（整数）
  "meta": { ... },           // 図の情報
  "page": { ... },           // 用紙
  "profile": "esa721",       // 既定の出力先
  "settings": { ... },       // 図ごとの設定
  "layers": [ ... ],         // レイヤ（1枚以上）。配列の先頭が一番奥（下）
  "activeLayer": "L...",     // 作業中のレイヤの id
  "underlays": [ ... ]       // 下絵（印刷されない）
}
```

### 3.1 meta

| 項目 | 型 | 内容 |
|---|---|---|
| `title` | 文字列 | 図の名前 |
| `created` | 文字列 | 作成日時（ISO 8601） |
| `modified` | 文字列 | 最後に保存した日時（ISO 8601） |
| `app` | 文字列 | 保存したソフトの名前（例 `tenzoo`） |

### 3.2 page（用紙）

| 項目 | 型 | 内容 |
|---|---|---|
| `paper` | 文字列 | 用紙の種類（下表）。寸法を自由に決めたときは `CUSTOM` |
| `width` | 数 | 幅 mm |
| `height` | 数 | 高さ mm |

| `paper` | 寸法 mm | 備考 |
|---|---|---|
| `EB5` | 203.2 × 254 | 点字用紙 B5（8×10インチ、32マス×22行）。エーデルの「B5」 |
| `EA4` | 254 × 279.4 | 点字用紙 A4（10×11インチ、40マス×24行）。エーデルの「A4」 |
| `B5` / `B5L` | 182 × 257 / 257 × 182 | ISO の B5 縦・横 |
| `A4` / `A4L` | 210 × 297 / 297 × 210 | ISO の A4 縦・横 |
| `A3` | 297 × 420 | ISO の A3 縦 |
| `CUSTOM` | `width` × `height` | 自由 |

`width`・`height` が正。`paper` は表示と、エーデル形式での用紙名の判断に使う。

### 3.3 profile（既定の出力先）

| 値 | 内容 |
|---|---|
| `esa721` | ESA721（エーデル互換）。格子は横 0.3454mm × 縦 0.3175mm（ESA721 の1ステップ）。点は S・M・L |
| `generic25` | 2.5mm 格子・1種類の点の点字プリンタ（目安） |
| `dpi20` | 20dpi（約 1.27mm）格子のプリンタ（目安） |
| `swell` | 立体コピー（カプセルペーパー）。格子なし |
| `free` | 格子なし（ベクトルそのまま） |

知らない値は `esa721` として扱う。

### 3.4 settings

| 項目 | 型 | 既定 | 内容 |
|---|---|---|---|
| `minDist` | 数または null | null | 点どうしの最小距離 mm。これより近い点は大きい方を残して1つにまとめる。null なら出力先の既定（ESA721 は 1.0）。0 でまとめない |
| `braille` | オブジェクト | 下表 | 点字の寸法（mm） |
| `edlFullArea` | 真偽 | false | 点字用紙 B5 で、エーデルの図の範囲（684 行）ではなく ESA721 の範囲いっぱい（725 行）まで使う |

`braille` の項目：

| 項目 | 既定 | 内容 |
|---|---|---|
| `dotPitchX` | 2.07 | マスの中の点の横の間隔（ESA721 の 6 目盛り） |
| `dotPitchY` | 2.06 | マスの中の点の縦の間隔（約 6.5 目盛り） |
| `cellPitch` | 5.18 | マスの間隔（15 目盛り） |
| `linePitch` | 10.48 | 行の間隔（33 目盛り） |

### 3.5 layers（レイヤ）

| 項目 | 型 | 内容 |
|---|---|---|
| `id` | 文字列 | 文書の中で一意 |
| `name` | 文字列 | 名前 |
| `visible` | 真偽 | 表示する。隠したレイヤは書き出しの既定の対象（「見えているレイヤ」）に含めない |
| `locked` | 真偽 | ロック（編集できない） |
| `side` | `front` / `back` | 用紙の表か裏か。`back` の点は両面印刷の裏面の点で、**表から見た位置**で描く（裏に打つときの左右反転は出力側が行う） |
| `color` | 文字列 | 画面での表示色（`#rrggbb`）。印刷には関係しない |
| `objects` | 配列 | 図形。配列の後ろほど手前 |

### 3.6 underlays（下絵）

なぞるための画像。印刷・書き出しには含めない。

| 項目 | 型 | 内容 |
|---|---|---|
| `id` | 文字列 | 一意 |
| `name` | 文字列 | 元のファイル名など |
| `src` | 文字列 | 画像の data URL（`data:image/png;base64,...` など） |
| `x`, `y`, `w`, `h` | 数 | 用紙上の位置と大きさ mm |
| `baseW`, `baseH` | 数 | 取り込んだときの大きさ mm（「大きさ %」の基準） |
| `opacity` | 数 | 0～1 |
| `visible` | 真偽 | 表示する |

## 4. 図形（objects）

### 4.1 共通の項目

| 項目 | 型 | 内容 |
|---|---|---|
| `id` | 文字列 | 必須。文書の中で一意 |
| `type` | 文字列 | 必須。図形の種類（4.3） |
| `style` | オブジェクト | 点の打ち方（4.2） |
| `edel` | オブジェクト | エーデルの .ezi から読み込んだ線・円弧だけが持つ。`{ "s": 間隔 }`（ESA721 の目盛り、整数）。これがあると、エーデルと同じ方法（長さ÷`s` を四捨五入して等分し、両端を含めて目盛りの整数に丸める）で点を置く |
| `source` | 文字列 | 取り込んだ元（例 `edl`）。記録用 |
| `kbd` | 真偽 | キーボードで続けて打った点の集まり（続きの点を同じ図形に足すための印） |

### 4.2 style

| 項目 | 型 | 既定 | 内容 |
|---|---|---|---|
| `stroke` | 真偽 | true | 輪郭線を点で描く |
| `dot` | `S`/`M`/`L` | `M` | 輪郭線の点の大きさ（記号では記号の点の大きさ） |
| `spacing` | 数 | 2.0 | 輪郭線の点の間隔 mm。角（25°以上曲がる所）には必ず点を置き、角と角の間を均等に割る |
| `line` | 文字列 | `solid` | `solid` 実線、`dashed` 破線（3間隔描いて2間隔あける）、`dotted` 点線（間隔の2倍）、`double` 二重線 |
| `width` | 数 | 2.8 | 二重線の2本の線の間の幅 mm（`line` が `double` のとき） |
| `arrow` | 文字列 | `none` | 開いた線の矢印：`none`・`start`・`end`・`both` |
| `fill` | オブジェクト／null | null | 面（閉じた図形のみ。4.4） |
| `clear` | 数 | 0 | 点字・記号の周りの余白 mm。図形の外接矩形をこれだけ広げた範囲にある、**ほかの図形の点**を出力しない |

### 4.3 図形の種類

| `type` | 項目 | 内容 |
|---|---|---|
| `path` | `points: [[x,y],...]`, `closed` | 直線（2点）・折れ線・多角形 |
| `curve` | `points`, `closed` | 通過点を結ぶ滑らかな曲線（Catmull-Rom スプライン） |
| `freehand` | `points`, `closed` | 手描きの線（間引いた点列を直線で結ぶ） |
| `arc` | `points: [始点, 終点, P3]` | 円弧。始点と終点を通る円の一部。P3 は円上の点でなくてよく、弦の垂直二等分線方向のふくらみ h ＝（P3 − 弦の中点）・弦の法線 だけが意味を持つ。半径 R ＝ (c²/4 + h²) / (2\|h\|)（c は弦の長さ）。h の符号でふくらむ側が決まる。エーデルの .ezi の種類 102 と同じ定義 |
| `rect` | `x, y, w, h, rot` | 四角形。`x, y` は回転前の左上、`rot` は中心まわりの回転 |
| `ellipse` | `cx, cy, rx, ry, rot` | 楕円（`rx = ry` で円） |
| `dots` | `points: [[x, y, size], ...]` | 点の集まり（点の道具、.edl の読み込み、点への変換の結果）。`size` は `S`/`M`/`L`（省略時は `style.dot`） |
| `braille` | `x, y, text, dot, cells?, metrics?` | 点字。`x, y` は1マス目の1の点の中心。`text` はかな・英数字・Unicode 点字（U+2800～）・改行。`dot` は点の大きさ（既定 `M`）。`text` が空で `cells`（6ビットの整数の配列、1の点＝bit0 … 6の点＝bit5、改行＝-1）があればそれを使う。`metrics` で `settings.braille` を図形ごとに上書きできる |
| `marker` | `x, y, shape, scale?` | 記号。`x, y` は中心。`shape` は `star`（星）・`cross`（十字）・`square`（四角）・`diamond`（ひし形）・`circle`（丸）・`triangle`（三角）・`dot`（1点）。点の配置は 4.5。`scale` は倍率（既定 1） |
| `mask` | `x, y, cell, w, h, rows` | 塗りつぶしで作った領域。`cell` mm のマス `w` × `h` 個の白黒画像で、左上が `x, y`。`rows` は各行のランの並び `[開始, 長さ, 開始, 長さ, ...]`（マス単位）。`style.fill` で中を塗る |

閉じた図形とは、`rect`・`ellipse`・`mask` と、`closed: true` の `path`・`curve`・`freehand`。

### 4.4 fill（面）

| 項目 | 型 | 既定 | 内容 |
|---|---|---|---|
| `pattern` | 文字列 | `grid` | 面の表現（下表） |
| `spacing` | 数 | 3.0 | 線どうし・点どうしの間隔 mm |
| `pitch` | 数 | 1.6 | 線の中の点の間隔 mm |
| `angle` | 数 | 0 | 模様の角度（度） |
| `dot` | `S`/`M`/`L` | `S` | 面の点の大きさ |
| `inset` | 数 | 1.5 | 輪郭線からの余白 mm（`stroke` が true のときだけ効く） |
| `seed` | 整数 | 12345 | `random` の乱数の種（同じ種なら同じ点になる） |

| `pattern` | 内容 |
|---|---|
| `grid` | 格子点（間隔 `spacing`） |
| `hex` | 千鳥（三角格子） |
| `dense` | ベタ（間隔 `pitch` の格子） |
| `hlines` / `vlines` | 横線 / 縦線（線の間隔 `spacing`、線の中の点の間隔 `pitch`） |
| `diag` / `diag2` | 斜線（／） / 斜線（＼） |
| `cross` / `xcross` | 格子線（＋） / 斜め格子（×） |
| `wave` / `zigzag` | 波線 / ジグザグ |
| `dashed` | 破線（3点描いて2点あける。段ごとに半周期ずらす） |
| `brick` | レンガ |
| `checker` | 市松（一辺 `spacing`×2 のブロック） |
| `circles` | 同心円（外接矩形の中心が中心） |
| `radial` | 放射線 |
| `random` | ランダム（砂目。点どうしは `spacing` 以上離す） |

模様は図形の外接矩形の中心を基準に `angle` だけ回して作り、図形の内側（偶奇規則）で、
輪郭線から `inset` 以上離れた点だけを使う。

### 4.5 記号の点の配置

ESA721 の目盛り（横 0.3454mm・縦 0.3175mm）で、中心からの位置を表す。navimap-assistant・edlprt の地図記号と同じ。

| `shape` | 点（目盛り） |
|---|---|
| `cross` | (0,−7) (−7,0) (0,0) (7,0) (0,7) |
| `square` | (−4,−4) (4,−4) (−4,4) (4,4) |
| `diamond` | (0,−7) (7,0) (0,7) (−7,0) |
| `star` | 半径 8、−90° から 72° おきの 5 点（四捨五入） |
| `circle` | 半径 7、0° から 60° おきの 6 点（四捨五入） |
| `triangle` | 半径 8、−90° から 120° おきの 3 点と、その各辺の中点（四捨五入） |
| `dot` | (0,0) |

## 5. 点への変換（出力するとき）

1. 対象のレイヤ（既定は見えているもの）の図形ごとに点を求める（mm）。
   - 線：輪郭を `spacing` で割る（角は残す）。破線・点線・二重線・矢印も同じ規則で点にする。
   - `edel` を持つ線・円弧：4.1 のエーデルの方法。
   - 面：4.4。点字：`settings.braille`（または `metrics`）の寸法。記号：4.5。
2. `style.clear` を持つ点字・記号の余白の中にある、ほかの図形の点を除く（表と裏は別々）。
3. 出力先に格子があれば、各点をいちばん近い格子点に合わせる。
4. 出力先にない点の大きさを、使える大きさに置き換える。
5. `minDist` より近い点を、大きい点を優先して1つにまとめる（表と裏は別々）。

## 6. 版と互換性

- `version` はこの仕様の版。第1版は `1`。
- 項目の追加など、古い版のソフトでも読める変更では `version` を上げない。読む側は知らない項目を無視する。
- 意味が変わる変更をするときは `version` を上げる。読む側は、自分より新しい版のファイルを開くとき、情報が失われる可能性を利用者に知らせる。
- 知らない `type` の図形は、表示・出力せずに残す（保存し直すときに消さない）。
- 省略された項目は既定値として扱う。

## 7. 例

```json
{
  "format": "tenzoo",
  "version": 1,
  "meta": { "title": "家", "created": "2026-11-06T10:00:00.000Z", "modified": "2026-11-06T10:05:00.000Z", "app": "tenzoo" },
  "page": { "paper": "EB5", "width": 203.2, "height": 254 },
  "profile": "esa721",
  "settings": { "minDist": null, "braille": { "dotPitchX": 2.07, "dotPitchY": 2.06, "cellPitch": 5.18, "linePitch": 10.48 } },
  "layers": [
    {
      "id": "L1", "name": "外形", "visible": true, "locked": false, "side": "front", "color": "#1d4ed8",
      "objects": [
        { "id": "o1", "type": "rect", "x": 40, "y": 110, "w": 70, "h": 60, "rot": 0,
          "style": { "stroke": true, "dot": "M", "spacing": 2, "line": "solid", "arrow": "none",
                     "fill": { "pattern": "hlines", "spacing": 3, "pitch": 1.6, "angle": 0, "dot": "S", "inset": 1.5 } } },
        { "id": "o2", "type": "path", "closed": true, "points": [[35, 110], [75, 75], [115, 110]],
          "style": { "stroke": true, "dot": "L", "spacing": 2.2, "line": "solid", "arrow": "none", "fill": null } },
        { "id": "o3", "type": "marker", "x": 150, "y": 90, "shape": "star", "style": { "dot": "L", "clear": 3.5 } },
        { "id": "o4", "type": "braille", "x": 40, "y": 190, "text": "いえ", "dot": "M", "style": { "clear": 1.5 } }
      ]
    }
  ],
  "activeLayer": "L1",
  "underlays": []
}
```
