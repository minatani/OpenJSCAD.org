# tenzoo のデータ形式

## 1. 考え方

- **ベクトルで保存する**：線・図形・面は「形」と「点の打ち方（スタイル）」で保存し、点そのものは保存しない。
  拡大縮小や点の間隔の変更、出力先の変更をしても情報が劣化しない。
- **出力先に依存しない**：座標はすべて mm（用紙の左上が原点、y は下向き）。プリンタの格子・点の種類への変換は出力時に
  プロファイル（`js/profiles.js`）で行う。ESA721 の3種の点はもちろん、他の点字プリンタや立体コピーにも同じデータから出せる。
- **拡張できる**：JSON なので、知らないキーは読み飛ばせる。`version` で形式の版を区別する。
- **点の大きさは論理名**（`L` 大点 / `M` 中点 / `S` 小点）。実際の直径・高さはプロファイルが決める。

## 2. tenzoo 形式（.tenzoo）

UTF-8 の JSON。

```jsonc
{
  "format": "tenzoo",          // 固定
  "version": 1,                // 形式の版
  "meta": { "title": "家と木", "created": "ISO 8601", "modified": "ISO 8601", "app": "tenzoo" },
  "page": { "paper": "EB5", "width": 203.2, "height": 254 },   // mm（EB5 = 点字用紙 B5）
  "profile": "esa721",          // 既定の出力先（esa721 | generic25 | dpi20 | swell | free）
  "settings": {
    "minDist": null,            // 点どうしの最小距離 mm（null ならプロファイルの既定値）
    "braille": { "dotPitchX": 2.07, "dotPitchY": 2.06, "cellPitch": 5.18, "linePitch": 10.48 }
  },
  "layers": [                   // 配列の先頭が一番奥
    {
      "id": "L...", "name": "外形", "visible": true, "locked": false, "color": "#1d4ed8",
      "side": "front",          // front | back（両面印刷の裏面）
      "objects": [ /* 図形（下記） */ ]
    }
  ],
  "activeLayer": "L...",
  "underlays": [                // 下絵（印刷されない）
    { "id": "u...", "name": "photo.jpg", "src": "data:image/jpeg;base64,...",
      "x": 10, "y": 20, "w": 160, "h": 120, "baseW": 160, "baseH": 120, "opacity": 0.4, "visible": true }
  ]
}
```

### 2.1 図形に共通のスタイル

```jsonc
"style": {
  "stroke": true,          // 輪郭線を点で描く
  "dot": "M",              // 輪郭線の点の大きさ L | M | S
  "spacing": 2.0,          // 輪郭線の点の間隔 mm（角には必ず点を置き、辺を均等に割る）
  "line": "solid",         // solid | dashed | dotted
  "arrow": "none",         // none | start | end | both（開いた線のみ）
  "fill": null | {         // 面（閉じた図形のみ）
    "pattern": "grid",     // grid hex dense hlines vlines diag diag2 cross xcross wave zigzag dashed brick checker circles radial random
    "spacing": 3.0,        // 線どうし・点どうしの間隔 mm
    "pitch": 1.6,          // 線の中の点の間隔 mm
    "angle": 0,            // 度
    "dot": "S",            // 面の点の大きさ
    "inset": 1.5           // 輪郭線からの余白 mm（stroke が true のとき有効）
  }
}
```

### 2.2 図形の種類

| type | 内容 |
|---|---|
| `path` | 折れ線・直線・多角形。`points: [[x,y],...]`, `closed` |
| `curve` | 通過点を結ぶ滑らかな曲線（Catmull-Rom）。`points`, `closed` |
| `arc` | 円弧。`points: [始点, 終点, ふくらみの点]`（エーデルの .ezi と同じ定義） |
| `freehand` | 手描き。`points`, `closed` |
| `rect` | 四角形。`x, y, w, h, rot`（rot は中心まわりのラジアン） |
| `ellipse` | 楕円。`cx, cy, rx, ry, rot` |
| `braille` | 点字。`x, y`（左上の点の中心）, `text`（かな・英数字・Unicode 点字）, `dot`（既定 M＝エーデルの大きさ 2）, `metrics`（任意で寸法を上書き） |
| `dots` | 点の集まり（.edl からの読み込み、点の道具、点への変換結果）。`points: [[x, y, size], ...]` |
| `mask` | 塗りつぶしで作った領域。`x, y, cell`（セルの大きさ mm）, `w, h`（セル数）, `rows`（各行のラン `[開始, 長さ, ...]`） |

すべての図形は `id` と `style` を持つ。エーデルから読み込んだ線・円弧は `edel: { s }`（.edl 目盛りでの点の間隔）を持ち、エーデルと同じ方法で点を置く。将来の図形の種類は新しい `type` として追加する（古い版は知らない種類を無視できる）。

## 3. エーデルの形式

公開仕様はない。利用者による実物ファイル（.edl 7点、.sebk 2点、.ezi）と ESA721 Ver'95 説明書・jmbraille の解析結果、
および tenji-editor の解析に基づく。「未解明」とした点は推測で実装している。

### 3.1 .edl（点図）

ASCII テキスト、行区切りは CRLF、最後の行のあとに改行はない（末尾に EOF 0x1A が付くことがある）。

```
EDELB5,33,485                 ← "EDEL" + 用紙名 + "," + 点の最小の y + "," + 最大の y
2NMAGNGAJN@ALNMANMT...        ← 点の大きさ（1桁）＋ 点の座標（4文字）の繰り返し
3LHBG
```

- 用紙名：`B5`（点字用紙 8×10インチ、32マス×22行、x 0～479）、`A4`（10×11インチ、40マス×24行、x 0～599）。
  tenzoo は A4 の y を 790 までにする（それより下に点があると ESA721 が紙を送り続ける現象への対策）
- 座標は x・y それぞれ2文字：値 = (上位 − 64) × 26 + (下位 − 64)。下位は `@`～`Y`（0～25）、上位は `@`～`Z` と A4 では `[` `\`（27, 28）
- 点は (y, x) の昇順。点の大きさが変わるところで行を変える。同じ座標の点はない
- 点の大きさ：`1` 小、`2` 中（点字の点）、`3` 大（ESA721 の `ESC ESC D 0/1/2`）。tenzoo では `S` / `M` / `L`
- 1目盛り＝ESA721 のプロッタの1ステップ：横（edl の x）0.3454mm、縦（edl の y）0.3175mm。1マス＝15、1行＝33
- 用紙の外（x < 0、x ≧ 用紙の幅）の点は書かない
- 拡張（エーデル本体の形式ではない。edlprt の解析資料による。tenzoo は読み書きに対応）
  - 複数ページ：`EDEL...` のヘッダ行がページの始まり。読み込むと各ページをレイヤにする（2ページ目以降は隠す）
  - 両面：大きさ `4` `5` `6` は裏面の `1` `2` `3`（表から見た座標）。tenzoo では「裏」にしたレイヤの点

### 3.2 .ezi（線の図形データ）

1行目が要素の数、2行目から1行1要素。空白区切りの整数 11 個（行末に空白）、CRLF。座標・間隔の単位は .edl と同じ。

| 種類 | 書式 | 意味 |
|---|---|---|
| `101` | `101 大きさ 間隔 x1 y1 x2 y2 0 0 0 0` | 線分 |
| `102` | `102 大きさ 間隔 x1 y1 x2 y2 x3 y3 0 0` | 円弧。始点・終点を通る円の一部。3点目は円上の点ではなく、弦の垂直二等分線方向のふくらみ h = (P3 − 弦の中点)・弦の法線 を与える。半径 R = (c²/4 + h²) / (2|h|) |

- 点の置き方：長さ L（円弧は弧の長さ）を間隔 s で割り、n = round(L/s)（1以上）に等分して、両端を含む n+1 点を整数に丸める
- 未解明：丸める前がちょうど .5 になる点の丸め方（実物との差は1目盛り以内）、円弧の n が round(L/s) か +1 か、各行末の `0 0 0 0`
- 面・手で打った点・点字は .ezi には無く、.edl だけにある

tenzoo での扱い：
- 読み込み：線分は端点がつながる同じ大きさ・間隔のものを折れ線にまとめ、円弧は `arc` 図形にする。どちらも `edel: { s: 間隔 }` を持ち、
  上の置き方で点を作る（.edl と同じ点になる）。.edl と組で開いた場合は、.edl に点がほとんど無い要素を隠したレイヤに、
  .ezi から作れない .edl の点（手で打った点など）を点のレイヤに入れる
- 書き出し：直線の折れ線は線分（101）、円弧は 102、それ以外の線（曲線・円・四角・手描き）は点の間隔ごとの短い線分にする（試験的）

### 3.3 .sebk（図のまとめ）

圧縮はない。「名前,大きさ 本体（大きさバイト）」を区切りなしで連結したもの。

```
Zu_1.edl,2406 <.edl そのもの>Zu_1.ezi,2025 <.ezi そのもの>fumi.data,1 32 21 ,<NUL×788>00 
```

- `fumi.data` は構造未解明（点字の文書領域らしい。中身のある実物が必要）。tenzoo は読み込みでは無視し、書き出しでは実物の空のもの（810 バイト）を付ける

## 4. 点への変換の手順（出力時）

1. 表示中（または指定）のレイヤの図形ごとに、輪郭線の点・面の点・点字の点を求める（mm）
2. 出力先プロファイルに格子があれば、各点を格子に合わせる
3. 出力先にない点の種類を、使える種類に置き換える
4. 「点どうしの最小距離」より近い点を、大きい点を優先して1つにまとめる
5. 各形式（.edl / SVG / PDF / PNG）に書き出す
